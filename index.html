Mathorium

Free AI math OCR. Convert an image, a screenshot, a photo of a textbook or your own handwriting into LaTeX, MathML, Word or Markdown — in batches, in your browser. Recognition runs on-device with Pix2Text, so there is no API key, no account and no upload. It is the open, genuinely free Mathpix alternative.

Frequently asked

Is Mathorium a free alternative to Mathpix?
Yes. Mathorium does the same core job — turning a picture of an equation into LaTeX — with no account, no API key, no page quota and no subscription. Recognition runs in your browser using the Pix2Text model, so there is no per-image cost to pass on.
Do my images get uploaded to a server?
Not for OCR. The offline engine downloads the model once and then recognises everything on your own device, so images never leave the browser. Cloud vision models are optional and only used if you pick one.
What can Mathorium export?
LaTeX, MathML, Word-ready OMML, Markdown, HTML, plain text, JSON and SVG. Batch results can be exported together, and any single expression can be copied straight into Word, Overleaf or Notion.
Does it read handwriting?
Yes, for reasonably clear handwriting. Printed textbook and paper equations are the most accurate; for messy handwriting a cloud vision model usually does better, and you can switch engines per image.
Does Mathorium work offline?
Yes. Once loaded it is installable as a PWA, and the OCR engine, the LaTeX renderer and the equation editor all work with no network. Only cloud AI chat and image generation need a connection.
